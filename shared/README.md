# shared/ — cartella di scambio

Posto dove ognuno carica materiale "al volo" per farlo vedere agli altri: appunti, bozze,
screenshot, tabelle, liste di canali, link. Il paper si scrive su **Overleaf**, non qui.
Quando serve, il materiale viene sistemato e spostato al posto giusto (`data/`, `memory/`, ...).

## Come caricare da browser

GitHub → cartella `shared/<tuo nome>/` → **Add file → Upload files** (oppure *Create new file*)
→ scrivi due parole nel messaggio di commit → **Commit changes** direttamente su `main`.

## Regole

1. **Ognuno scrive solo nella propria cartella** (`Marco/`, `Simone/`, `Riccardo/`): così non ci
   sono conflitti.
2. **Niente credenziali**: niente `.env`, `.session`, codici di login, API id/hash, numeri di telefono.
3. **Niente dati personali**: niente messaggi di utenti copiati, screenshot con nomi/foto di
   persone o username di utenti. Nomi e link di canali/gruppi pubblici vanno bene.
4. File **sotto i 100 MB** (limite di GitHub).
5. Nome dei file con la **data davanti**: `2026-09-29-canali-airdrop.md`, così si capisce cosa è nuovo.
6. Se qualcosa va **deciso** (criteri, soglie, scelte di metodo), scrivilo anche in
   `memory/decisions.md` o chiedi a Riccardo di farlo: finisce nel paper.
